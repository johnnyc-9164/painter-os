# Core beliefs

Human decisions set goals and genuine business-policy choices; agents execute bounded work and return inspectable evidence. A failed run should expose a missing capability or reproducible defect rather than an instruction to try harder.

Make authority explicit: one current writer per aggregate, cloud identity from Better Auth, membership checked server-side, typed published projections for the public app. Parse external data at the existing boundary. Preserve original signed/payment evidence; invented evidence cannot bridge a store cutover.

Reuse shared utilities/components and tested seams. Enforce dependency direction and correctness centrally; let implementations vary inside those boundaries. If a review reveals a recurring error, improve the relevant doc or executable check.

Keep changes small and reversible. Existing monoliths are tracked debt, not a reason to bundle refactors into unrelated tasks. A passing synthetic test proves its tested behavior and runtime only. Independent review and exact-head receipts remain required.
