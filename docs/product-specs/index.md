October 4 sequencing: first harden the individually deployed/white-label model; preserve a later self-service SaaS path rather than launch a multi-tenant rebuild now. The future offer combines each contractor's configurable public website with CRM, estimating, jobs and invoicing.

The preserved [product IR](../ir/system.ir.yaml) describes ambition, not current completion. The [freeze](../contracts/issue-2-freeze.md) defines actual authority and undecided cutover/deposit policy. Follow current issues for acceptance criteria. Website, admin and contractor customer-facing site are distinct surfaces.

Prioritize one real contractor's complete workflow and safe identity/tenant boundaries. Self-service subscription billing/onboarding remains later scope unless Johnny explicitly changes the sequencing. [Quality](../QUALITY_SCORE.md) separates local coverage from live operation.
